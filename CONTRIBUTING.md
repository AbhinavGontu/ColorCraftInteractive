# Contributing to ColorCraft

We welcome contributions!

## Getting Started

1.  **Clone the repo**: `git clone ...`
2.  **Install**: `npm install`
3.  **Run**: `npm run dev`

## Pull Requests

- Please keep PRs focused and small.
- Run `npm run lint` before key submission.
- Ensure the app builds with `npm run build`.

## Code Style

- We use **TypeScript**. Please avoid `any`.
- We use **Zustand** for state management.
- We use **Prettier** for formatting.

Thank you for helping improve ColorCraft!
